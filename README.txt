REZINA — A LITTLE UNIVERSE
===========================

HOW TO OPEN
1. Extract the ZIP file.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Open index.html in Chrome, Edge, Firefox or Safari.

PERSONALIZED DETAILS
- Rezina Parbin
- Aminul Islam
- Gift countdown unlocks on 2 January 2027 at 12:00 AM (visitor's local time).
- The gift section intentionally avoids mentioning a birthday.

EDIT THE DATE
Open script.js and find:
const targetDate=new Date(2027,0,2,0,0,0);
JavaScript months start at zero: January = 0.

NOTE
The site uses Google Fonts when internet is available. The rest of the website,
photos, animations and countdown work offline.
